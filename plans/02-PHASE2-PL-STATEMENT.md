# Phase 2: P&L Statement (Profit & Loss)

## Goal
Broker can see a proper P&L statement: Income (brokerage earned) − Expenses (operating costs) = Net Profit/Loss, for any date range.

## Depends On
Phase 1 (Expense Tracking) — needs expense data.

## API Route: `src/app/api/reports/profit-loss/route.ts`

**GET** `/api/reports/profit-loss?range=month|quarter|year|custom&from=ISO&to=ISO`
- Requires auth (`getCurrentBroker`)
- Computes:

### Income Section
```
Brokerage Income:
  - Brokerage eligible (accrued + scheduled + paid) in date range
  - Brokerage actually paid out in date range
  - Total Income = eligible brokerage in range
  
Other Income (future): invoice payments (Phase 4)
  
Total Income = brokerage income + other income
```

### Expense Section
```
Operating Expenses (from Expense table, filtered by date range):
  - Travel: ₹X
  - Phone: ₹X
  - Staff Salary: ₹X
  - Office Rent: ₹X
  - Marketing: ₹X
  - Miscellaneous: ₹X
  
Total Expenses = sum of all categories
```

### Net Result
```
Net Profit = Total Income − Total Expenses
Margin % = (Net Profit / Total Income) × 100
```

### Response Shape
```typescript
{
  range: { start: ISO, end: ISO, label: "August 2026" },
  income: {
    brokerageEligible: number,
    brokeragePaidOut: number,
    totalIncome: number,
  },
  expenses: {
    travel: number,
    phone: number,
    staff_salary: number,
    office_rent: number,
    marketing: number,
    miscellaneous: number,
    totalExpenses: number,
  },
  net: {
    profit: number,     // can be negative (loss)
    marginPercent: number,
    isProfit: boolean,
  },
  comparison: {
    previousRangeProfit: number,
    changePercent: number,  // % change vs previous period
  }
}
```
